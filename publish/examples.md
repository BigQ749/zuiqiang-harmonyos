不要抄业务文案。只抄壳、签名、商店栏和踩坑。商店名以各产品 `store/` 材料为准。

## 想吃先停（主人也会说仙庭）

| 项 | 值 |
|---|---|
| 产品根 | `D:\APP\changui` |
| 小程序（只读，不提审） | `D:\APP\changui-mp` |
| 鸿蒙工程 | `D:\APP\changui\harmony` |
| 包名 | `com.xiangchi.xianting.hmos` |
| 显示名 | 想吃先停 |
| 类型 | 单机；演示点单，不真扣款，不真出餐 |
| 上传物 | 桌面 `想吃先停-1.0.0-signed.app` |

踩过的坑：

1. 包名先写成 `com.xiangchi.xianting`，AGC 已是 `.hmos`，工程必须改。
2. rawfile 打成 ES module → 白屏「正在打开…」。改 IIFE。
3. 未签名 `.app` → 解析失败 / 完整性失败 / 992。
4. 截图打成 1080×2340。后台要 9:16 的 1080×1920。
5. 先打开页面再写 localStorage，10 张都停在开户页。要先写入演示数据。
6. 证书文件名变成 `xiangchi.cer.cer`、`xiangchi.p7bRelease.p7b`。
7. 包里有 INTERNET 不能选单机。删权限后要重签。
8. 模拟器报 008010055：空闲内存不到 4GB。浏览器预览不能当上架包。
9. 鸿蒙上用 canvas 出图：不要 `toBlob` 配跨域图，改 `toDataURL`。

审核备注要写明：不提供真实配送，不真实收款。

## 锻体（目录名 zhugu）

| 项 | 值 |
|---|---|
| 产品根 | `D:\APP\zhugu` |
| 鸿蒙工程 | `D:\APP\zhugu\harmony` |
| 鸿蒙包名 | `com.duanti.app.hmos` |
| 安卓包名 | `com.zhugu.app` |
| 版本 | 1.0.0 |
| 显示名 | 锻体 |
| 类型 | 单机。体修题材的健身记录。不拍照、不估热量、不设账号 |
| 隐私页 | 公网静态页，政策和权利填同一个 https |
| 鸿蒙上传物 | 桌面 `锻体上传包.app` |
| 安卓上传物 | 桌面 `锻体安卓.apk` |
| 图标 | 桌面 216×216 方角 PNG |
| 截图 | 桌面文件夹，10 张 1080×1920 真界面 |

踩过的坑：

1. 鸿蒙和安卓必须是两个 AGC 应用。鸿蒙栏传 `.app`，安卓栏传 APK。
2. 安卓包名不能以 `.huawei` 结尾。
3. 云测把鸿蒙包丢到鸿蒙 4（P40 Pro）、鸿蒙 2（nova 9）、鸿蒙 3（Mate 30）上，首次和再次启动全部失败。这三台只能测安卓包。DevEco 模拟器是鸿蒙 5/6，模拟不了这三台。
4. 安卓壳若只拦截 `https://appassets.androidplatform.net`，老网页组件不拦截，云测记启动失败。改 `file:///android_asset/www/index.html`。
5. 应用图标栏是 216×216，不要预圆角。
6. 一句话简介有 17 字上限。介绍给用户看，短、真，先写体裁，不写最佳和首创。
7. 个人信息选「是」。存储不要写服务器，写只在本机，直到焚档或卸载。
8. 应用内隐私页不够，必须有公网网址。
9. 安卓方式一仍要上传密钥的 PEM，不要把 jks 传上去。`apksigner` 用环境变量传口令。
10. 耀星计划申请书不是上架必做。不编注册资本、下载量、收入、独家首发。公司登记以营业执照为准。

产品红线以 `D:\APP\zhugu\AGENTS.md` 为准：不接云、不估热量、境界不可手改、重量默认不记。

## 下一款怎么套

1. 先框产品。抄 IIFE 壳和签名步骤，不抄店名、香钟文案或体修词。
2. AGC 新建 HarmonyOS 应用，包名带 `.hmos`，最低鸿蒙 5。
3. 能离线就单机，两个包都不要网络权限。
4. 浏览器点通后，再进模拟器点通，再签名。
5. 截图、216 图标、公网隐私页和短文案可以在等证书时做完。
6. 要覆盖老鸿蒙手机，再单独做安卓应用，用 file 打开网页。
7. 云测时按包选机器。只上传对应的已签名文件。
