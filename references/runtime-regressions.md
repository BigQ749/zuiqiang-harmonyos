# 有条件的原生与 Web 回归要点

只检查本次产品具有的能力。先定位可复现链路，再做最小修复；目标设备未验证须明确列出。

## 相机、图片与相册

- CameraPicker 在前台有效 UIAbilityContext、UI 线程/队列中调用，防重复点击并及时显示进展；区分取消、授权拒绝、设备不可用、参数错误和超时。核对 installed SDK 声明及[官方 CameraPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/camera-picker)，PickerProfile 使用文档允许的数据对象，不能把只读类/命名空间当实例写属性。不要把所有异常都叫“相机没有打开”。
- 原生取景的 Surface 需要实际可见；检查覆盖它的 WebView 和 .stage/.device/.device-screen 背景、透明区域、层级和尺寸。取景修复后继续验拍摄结果、返回和保存，不能只看到相机页就算完成。
- 系统选择照片后先按授权 URI 读取、复制本机快照，处理临时授权/FD 生命周期、格式和方向；ArkWeb 不一定能直接加载原始 URI。轻图选照“有尺寸、图片裂开”说明元信息不等于图像可解码显示。
- 夜声旧包能显示新包不能时，对比最终包内资源路径、大小写、URL 编码、CSS 引用、图片格式、base/data/blob/resource 解析与桥接。不要盲目开全局网络/跨域权限。CSS mask 外部资源失败的图标可用真实内联 SVG 等本地稳定方式修复，仍核对目标 ArkWeb 渲染。
- 相册保存采用明确状态：用户同意/取消→目标 URI 创建→写入复制→关闭与系统提交→返回成功。核心写入完成才提示成功。对不支持 fsync/readback/元数据读取的授权目标，**可选校验失败不能覆盖已完成写入造成“没能存进相册”误报**；核心失败也不能吞异常假成功。只在必要时回滚确属本次且未提交的半成品，不删除已保存用户照片，不因重试产生多份。

## 二维码导入

- 用真实生成码原图、用户整屏截图、相册导出的压缩图分别测试；保留当前和已发布编码样本。中文“下节课1.”、历史 ASCII 标识、BOM/空白/换行规范化只做有证据的兼容，不能将任意码当有效课表。
- QR 解码器返回的 text 和 binaryData 可能编码路径不同，压缩二进制不要只走损坏的字符串转换。以原始 binaryData 处理字节，分离头、base64/压缩/解压、schema 校验各阶段；有界多尺寸/裁切/方向识别，限制像素、解压大小和课程数量。
- 导入失败准确区分未发现码、非下节课码、版本不支持、损坏内容；合法码失败不能统一报“不是下节课的码”。先预览再合并/替换，不直接覆盖现有课表。新增格式应说明旧版是否可读，不能仅发布新生成器不维护读端兼容。
- 网页用用户截图识别成功只证明该流程，不证明鸿蒙 Picker 返回 URI 和 native Web bridge 端到端成功。

## 闹钟、导航和系统 UI

- 重复日期空数组是合法“无重复”状态，不能用 falsy/default 恢复全选。保存→退出/进程重建→编辑仍保留空数组，调度按单次处理；历史数据迁移只补缺失字段，不覆盖用户已清空设置。
- 系统返回按应用路由/弹层栈回上一页；只有根页才按平台约定退出。状态栏时间电量在浅色底为深色，顶部/底部安全区与主题统一；检查编辑文字、按钮热区和小屏字体缩放，不用假状态栏遮住系统状态。
- 清醒闹钟对齐用户确认的 Android UI/路径，同时保持 HarmonyOS 摄影和调度实现；不能只更换 CSS 就宣称原生相机已可用。

## 提醒、后台、音频

- 正确时刻 1700002 曾为系统代理提醒数量上限：维护本应用已创建 reminderId，更新/结束/确认/重建时有序取消旧项，防并发重复预定。按官方错误详情核实，不能不加判断删其他有效提醒或无限重试。
- 到点提醒只有一条用户需要的通知，避免系统代理提醒与本地 publish 双发；点击确认“我还在”要清理已处理通知和对应状态。拒绝后设置可再次请求/跳转，设置页不能无响应；允许权限不等于保证横幅、铃声或锁屏显示，仍需通知渠道/插槽、系统设置和实际到点链路核实。
- 不能用无声循环音频或虚假的 audioPlayback 后台任务维持计时。系统“音视频启动加载中”可能来自声明的媒体后台任务，不是改通知文字就能消除；删除与真实播放无关的任务，选平台允许的提醒方案。
- 安放曾因退后台占用传感器拒审；本用户已决定移除移动检测，改为前台会话离开提醒。不要保留后台加速度订阅或伪装媒体保活。区分 Home、锁屏、亮屏、返回、进程重建，按系统能力实现并实测；不能承诺强杀后继续或把息屏一律判违规。长按结束需有按压进度、取消和成功清理，实际能停止警报/会话。
- 夜声暂停/恢复统一由真实播放器状态驱动，AVSession 命令、Web UI、播放位置与关闭计时同步；暂停重开系统卡不能自行恢复计时。FD 在播放器使用期间有效，播放才开启合法后台任务，停止后释放。系统卡状态、计时和声音都要验，不能只观察读秒。
