# 交付契约与可迁移执行（2026-10-21）

本目录记录用户项目的实际返工经验；示例不是所有应用都必须具备的功能，也不是华为永久不变的政策。执行时以当前产品、最终包、当前控制台和对应 SDK 官方文档为准。任务只涉及一个问题时，只读取相关专项。

## 先确定唯一产品事实

在产品 store/ 中维护可机器读取的发布清单，字段按需要增减：产品中文名、平台、bundleName/applicationId、AGC appId/projectId、源码路径/提交、上一发布版本、本次 versionName/versionCode、最终文件名/大小/SHA256、发布证书指纹（不含私钥口令）、图标和截图路径/顺序、政策记录 ID 与语言、数据/权限清单、自检任务 ID、设备 OS/API、操作时间及是否允许提交。

- 品牌名以用户确认的真实名称为准：本次是 **刻时水印相机**，不是“课时水印相机”；下节课上传件不得显示为 kejian。名称同步商店、安装桌面标签、应用标题、各语言资源、政策、截图、更新说明和最终包。
- `.app` 是 HarmonyOS 发布格式；APK 是 Android 发布格式，不能改扩展名转换。已上线产品保持包名、签名继承和用户数据兼容，不能为了套模板重新建包名。
- 新建项目才采用可覆盖的技术默认。既有 Android 效果可作为功能/UI 基线，但迁移须实现本平台 API 和生命周期；不能仅替换网页后宣布原生权限和后台能力一致。
- 同产品多版本用版本号、代码和哈希识别，不按修改时间或文件名“最新”猜测。用户指定旧版为已通过基线时保留基线，单独列出新旧差异。

## 权限边界与验收层级

用户授权准备/上传/保存，不自动包含提交应用审核、协议审核或上架。明确要求先停的任务止于草稿；只在后续收到对应授权时提交。自检任务若会产生明确额外付费，先按实际授权处理费用。

分别记录以下事实，不相互代替：源码静态检查、编译完成、内外包验签、最终包资源检查、网页运行、模拟器、目标真机、平台合法性已达标、云自检报告、人工审核、实际生效。没有设备就标“目标设备未验证”，不能保证审核通过。

用户要求发布自检时：上传后启动平台自检/云测试，选择与包匹配的 OS/API，记录 taskId、包版本、设备、状态、报告结论与未完成项。队列中不写“通过”；平台无入口或账号无权限就记录阻塞与页面证据，不假装已启动。新增/运行代码测试仍遵循当前会话指令。

## 工具、机器与协作

- 工具路径、证书位置、浏览器连接和系统版本通过当前机器发现；不硬编码个人绝对路径、固定盘符、调试端口或 cookie。`defaults.json` 仅是本机历史参考，不能替代探测。
- 私钥、口令、登录态、验证码、CDP WebSocket 地址、预签名上传 URL 不打印、不写 Git、不放交接文档。证书与 Profile 的公开元数据可用于核对，但仅提交确有需要且允许公开的资料。
- 浏览器优先使用实际可用的连接工具；只有用户已授权 Chrome 调试连接/脚本时才沿用该方式。工具只能看到登录页时不声称已登录，不复用失效句柄。
- 并行任务按产品/文件分工；同一后台 tab 只允许一个操作者。上传未完成时不要导航；读写前核对 appId、projectId、平台和版本，不从其他产品复制 projectId。
- 技能更新只提交本轮拥有的改动。旧有未提交修改不得顺手提交或回退；发现真实失败后将症状、证据、最小修复、验证边界补到 case ledger，再提炼有适用条件的规则。

## 完成记录

交付中文 `<应用名>-<版本>-鸿蒙上传包.app` 及最小操作说明。报告需说明：实际修改、最终哈希、后台实际选中版本、政策修改和生效状态、自检任务状态、目标设备验证边界、是否提交。不要用“已上传”代替“已选入该版本并重新打开核对”。
