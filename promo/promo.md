# 鸿蒙 App 社交宣传图册

把真实产品讲清楚，做出用户可直接发布、可预览、可继续修改的图片。**复用制作方法，重新选择视觉方案。** 不把某一款产品的配色、页数、大标题位置或手机坐标变成其他 App 的固定要求。

应用市场必填截图（1080×1920）仍按根目录 [shots.md](../shots.md)；本目录做的是小红书 / 朋友圈等**社交宣传图**，尺寸与构图另选。

## 开始时确认的四件事

从用户说明、当前项目和现有素材中确定：产品名称与用途、目标受众、发布场景、要展示的版本。信息足够就直接制作；只询问会影响准确性或交付结果的缺失信息。

- 用户要宣传已上架版本时，先找该版本的截图、构建产物或上传包。当前源码的最新版本不能自动视为已经上架。
- 用户给参考图时，先看图再设计。社交平台截屏中的账号、评论区、点赞栏、播放进度不属于宣传素材。
- 上架状态不明确时，使用产品介绍或体验引导；只有状态有依据时才写「已上架」。下载链接、二维码必须实际可用。
- 准备一个短的视觉方向说明：受众、主色、字体气质、构图理由、每页讲什么。避免为普通设计选择反复要求确认。

## 按产品选择设计

读 [视觉决策与排版技巧](references/visual-direction.md)，根据 App 内容选择方向，而不是按技能名称套手机海报模板。

1. 提取产品自身的图标、界面色、典型内容和表达语气。参考图只提供视觉语言，不复制其他产品素材或可识别的整套设计。
2. 挑最有说服力的真实功能。通常可以组织为封面、核心体验、独特功能、结果或记录、下载收尾；不强行凑页，也不固定八页。
3. 每页一个重点，用自然、具体的中文标题。文案与现有功能一致，不写虚构数据、未实现的功能或无依据的效果保证。
4. 同套图保持字体、色彩关系、边距和手机材质一致；允许单手机、双手机、局部细节、餐单或内容卡片交替出现。只有用户明确要求时才把手机位置固定为每页相同。
5. 默认优先真实截图与精确排版。AI 生成可用于合适的装饰或场景背景，不能重画 App 界面、文字、图标细节或实际功能。减少模板化装饰与失真，不能承诺绕过 AI 检测或保证检测结论。

## 截图与制作

涉及网页模拟截图、旧包取图、批量导出或 Canva 时，读 [真实截图、版本替换与交付](references/production.md)。

- 从实际可操作的 App 或它的手机模拟网页截屏，屏幕按真实比例显示。390×844 是可用示例，不是所有设备的硬性尺寸。
- 先确认页面、字体、图片和必要动效已经就绪。使用独立浏览器环境存放演示数据，不清理或覆盖用户真实记录。
- 手机框应符合鸿蒙设备的视觉特征，摄像孔、边框、状态栏与安全区协调。保留截图比例，不拉伸，也不让手机壳盖住关键按钮。
- 需要特殊状态时通过真实界面进入，例如实际生成分享卡、打开图片预览、完成模拟订单。不要用伪造的 UI 卡片代替。
- 推荐 HTML/CSS 加 Chrome 精确排版与导出，也可使用 Canva 或其他当前可用工具。选择能控制中文字体、比例和细节的方式；Canva 是可选编辑渠道，不是强制依赖。

## 在已有图册上改图

用户说「保留这版，在它上面换图」时：

1. 保存原图册与原编辑设计，另建有明确版本标识的目录或设计。
2. 确认图片来自哪个版本，逐项建立店铺或商品名称与图片的对应关系。
3. 优先复用排版源文件，只替换对应截图或图片资源，重导出受影响页。未受影响页可原样保留。
4. 使用临时资源映射或独立副本截图，不为了宣传图替换正式 App 的资源、改代码或重新打包。
5. 若只恢复旧图片而继续使用当前页面布局，在交付说明中说明这一点；不能声称整页就是旧版真机截图。

## 交付和检查

尺寸按用户与发布场景确定。社交图册可采用 3:4，例如 JPG 1080×1440、高清 PNG 2160×2880；横向、方图和其他比例也可选。应用市场素材另查 [shots.md](../shots.md)。

交付只保留有用的结果：

- 按顺序命名的发布图片、需要时的高清原图。
- 总览与可放大预览，方便用户按页码反馈。
- 简短发布文案、素材或版本说明。
- 可继续修改的排版源文件；需要时另附整本 PDF 或 Canva 编辑链接。
- 用户需要桌面文件时，按本机实际桌面路径放入独立文件夹。跨电脑使用时打包技能或图册，不包含密钥与签名材料。

自己看总览，再看每页大图。检查中文断行、落单字、对比度、手机比例、图片对应、完整边框、页脚间距、下载引导与版本准确性。PDF 或 Canva 导入后也要检查；不能只凭导出成功或文字提取成功就认为视觉无误。

最终告诉用户：完成了哪套、放在哪里、用哪些图片直接发布、从哪里修改。展示一张总览或代表图。工具不可用时仍交付本地成果，并说明实际未完成的部分。
